Free static MVP

한글 사진/문장을 한국어 음성으로 읽기

이미지는 브라우저에서 OCR로 읽고, 문장은 기기 내장 한국어 음성으로 재생합니다. 서버·API 키·백그라운드 PC 실행 없이 동작하는 MVP입니다.

1. 한글 입력

사진을 선택하거나 아래에 직접 입력하세요.

2. 음성 선택

목록은 브라우저/OS가 제공하는 한국어 음성입니다. 기기마다 다를 수 있습니다.

무료 배포 방식

  • GitHub Pages, Cloudflare Pages, Netlify, Vercel 무료 플랜에 그대로 배포 가능합니다.
  • Tesseract.js는 CDN에서 불러오며 OCR은 사용자 브라우저에서 실행됩니다.
  • Web Speech API를 사용하므로 별도 TTS 서버 비용이 없습니다.
